% Attrition table: the starting universe is the 335 concepts drawn from the
% 6088 accepted across the transfer sweep by two criteria -- off-manifold
% fraction in [0.6, 0.8], the share of the concept's mapped direction lying
% outside the recipient's principal subspace (taken at 90 percent of
% variance), and acceptance count in [200, 499]. Every concept is accounted
% for, and neither loss is a negative result. One concept's donor and
% recipient require mutually incompatible TabICL versions, so it could never
% be searched. Eleven concepts transfer only into CARTE, the one recipient
% refit per dataset rather than frozen; rebuilding its tail to read a patch
% moves predictions by 0.032 against a median transfer effect of 0.012 on
% those rows, so the measurement noise exceeds the quantity measured and the
% readout is not attempted. That is missing measurement, not a measured
% null. The donor-side patch is unaffected in both cases: whether an input
% edit suppresses the concept never involves the recipient.
%
% Character table: quartiles are of the observed rank distribution, not
% fixed thresholds. Suppression is bimodal -- a patch either drives the
% concept's activation to exactly zero or stalls partway, with almost
% nothing between -- so the extinguished rate is reported rather than a
% median, which would be a step function of that rate: it reads 1.00
% whenever the rate clears 50 percent and drops into the lower cluster
% when it does not. Transfer rank is taken over every concept the greedy
% accepted at a row, nearly all of which fall outside the locked set. The
% concepts in a row's accept list that are themselves in the locked set
% number 1 at the Q1 median and 16 at the Q4 median, so the high-rank
% quartiles concentrate on shared rows and their patches are not independent
% observations.
% ---------------------------------------------------------------------
